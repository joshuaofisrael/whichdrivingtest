Frequently asked questions

Why do so many rows say the figure was not clearly published?

The official pages we opened did not state a question count or a passing score we could confirm. That is common. Check the state's own knowledge test page before you plan around a number.

Is the permit test the same as the license knowledge test?

Often the knowledge exam for a learner permit uses the same material as a first license exam, but some states publish different rules for teens, adults, or previously licensed drivers. Read the state's own page for the path you are on.

Do you copy practice tests from DMV handbooks?

No. This site does not republish handbook practice questions. It only records counts and passing scores when the licensing agency states them.
