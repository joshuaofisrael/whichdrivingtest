How to use these driving test guides

By Which Driving Test. Last checked 16 Nov 2026.

Not a government site. This is general information, not legal advice. Rules and fees change. Check your state licensing agency before you apply. Read the disclaimer.

Quick answer

Pick the state where you will apply, read the table, then open the official link and confirm the figure before you rely on it.

Pick the right state

Read the state that will issue the permit or license. If you are moving, that is the new state, not the one on your current card. A license from another state has its own section on the state page.

Read the table, then the official page

The state page leads with ages, whether a written test and a road test are required, practice hours, REAL ID, and fees. A fee appears only when the agency page prints a dollar amount. "Not clearly published" means we did not confirm it. It does not mean the rule is zero, waived, or free.

REAL ID is not the same question as "may I drive"

REAL ID is a federal card standard. Teen graduated licensing is the state path for young drivers. Both are linked from the state page. The federal REAL ID guide explains the federal part. The state page lists that state's documents.

What we do not do

We do not sell appointments, driving lessons, or insurance. We do not copy a whole handbook. We do not use test prep sites as sources. If a number is not on the official page we opened, it is not on this site.

Frequently asked questions

Can I use this site instead of the state DMV?

No. This is general information. The state agency page controls, and rules and fees change.

Why is a fee missing?

Because a dollar amount was not confirmed on the official page. Missing means we did not guess.

How do I report a wrong figure?

Email the address on the contact page with the page address and a link to the official agency page that shows the current rule.
