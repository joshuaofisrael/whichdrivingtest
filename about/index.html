About

What this site is

Which Driving Test is an independent guide to state driving tests and license rules. It explains the learner permit, the written test, the road test, REAL ID documents, published fees, moving a license from another state, and teen graduated licensing. A state guide is published only when that state's own licensing page can be quoted. It is not affiliated with any DMV.

Massachusetts, Illinois, and Colorado are not yet covered because the official sites could not be quoted.

What this site is not

It is not a state DMV, BMV, MVD, RMV, or secretary of state. It does not issue permits, book road tests, or take payment. It is not legal advice.

How the pages are written

Each state page is drawn from that state's own licensing agency and cites the page. See sources and methods.
