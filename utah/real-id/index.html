Utah REAL ID documents

By Which Driving Test. Last checked 16 Nov 2026.

Not a government site. This is general information, not legal advice. Rules and fees change. Check your state licensing agency before you apply. Read the disclaimer.

REAL ID is a federal card standard. TSA says enforcement began on May 7, 2025, for boarding a federally regulated commercial aircraft, certain federal facilities, and nuclear power plants. A state may still issue a license that is not REAL ID compliant. Driving rules come from the state. Federal REAL ID guide.

Utah describes a REAL ID credential as a driver license or ID with a gold star in the upper right corner. The division's site points readers to the Department of Public Safety notice. State REAL ID page (official site)

Quick answer

Use the state list below for documents. Use TSA only for the federal purpose of the card.

Documents the state page lists

  • Birth certificate. One identity option is a certified birth certificate from the state vital-records office. Source (official site)
  • Social Security card. A signed Social Security card is one accepted proof of the Social Security number. Source (official site)
  • Utah address. Two documents showing name and address, dated within 90 days, prove a Utah address. Source (official site)

This is a short reading of the official list, not the filing packet itself. Bring what the agency page names.

Frequently asked questions

Is a REAL ID required to drive in Utah?

TSA describes REAL ID for federal purposes such as commercial flights and certain federal facilities. Driving privileges come from the state license. This guide does not treat REAL ID as the rule for whether you may drive.

What documents does Utah list for a REAL ID?

The short list on this page is drawn from the state agency. The official page is the list to bring.

Does Utah issue an Enhanced Driver License?

The federal guide names the five Enhanced Driver License states. Confirm any card mark with the state agency.
